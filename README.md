# 당근 카페 계산기

개인용 오프라인 계산기 (기본·대출·할부·생활·부동산). 깃허브 페이지 저장소 이름: `carrot-calculator`

## 올리기
1. zip을 풀어 나온 파일 전체를 저장소 맨 위에 올립니다 (폴더째 올리지 않기).
2. 올리기 전에 `version.json`을 열어 `"app":"carrot-calculator"`와 버전 번호를 확인합니다.
3. 저장소 Settings → Pages → Branch: main / (root) → Save. 1~2분 뒤 `https://계정.github.io/carrot-calculator/` 에서 열립니다.
4. 폰 크롬으로 한 번 열고 [설치] 또는 메뉴(⋮) → 앱 설치. 아이폰은 Safari 공유 → 홈 화면에 추가.

## 업데이트
- 바뀐 파일만 덮어 올리면 됩니다. 앱을 다시 열면 저절로 바뀌거나, 위에 뜨는 [바꾸기]를 누릅니다.
- 홈 화면 아이콘 그림은 하루 이상 걸릴 수 있습니다.

## 계산 기준
- 대출은 고정 연이율·매월 납입 가정, 할부는 원금균등(잔여 원금 × 월 수수료율).
- 부동산 요율은 2026년 11월 26일 확인 기준이며 자동 업데이트되지 않습니다. 결과는 예상액입니다.
- 양도세는 개인 단독명의 주택, 2년 이상 보유, 1세대 1주택 비과세 요건 충족 또는 기본세율만 계산합니다. 중과·공동명의·감면은 계산하지 않습니다.
- 중개보수는 1인 기준 상한이며 부가세 별도입니다.
